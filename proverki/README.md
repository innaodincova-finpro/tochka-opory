# Проверки кабинета «Точка опоры»

Здесь лежат автоматические проверки кабинета. Они открывают кабинет в браузере без экрана, нажимают кнопки как человек и сверяют результат: записи сохраняются, код входа работает, цифры сходятся, ошибок нет.

Нужны исполнителю, который дорабатывает кабинет: перед выкладкой новой версии все проверки должны пройти.

Как запустить:
1. Установить Python и Playwright (`pip install playwright`, затем `playwright install chromium`).
2. Из папки с кабинетом запустить простой сервер так, чтобы кабинет открывался по адресу http://127.0.0.1:8765/v11/index.html (папка `v11` — копия кабинета).
3. Запустить проверки по очереди: `python t_stage1.py out/`, затем `python t_stage2.py` и остальные.
4. В конце каждой проверки строка «ИТОГ N из N». Строки FAIL — ошибки.
